# Fiance

Explore automated finance tools.

## Strategy Return Simulator

The Strategy Lab tab fetches updated Yahoo Finance adjusted-close history through the latest available session and compares multiple rule-based strategies from a selected start date.

Included strategies:

- Buy & Hold
- 20/50 simple moving-average crossover
- 50/200 simple moving-average crossover
- 63 trading-day momentum
- RSI mean reversion

Run locally:

```bash
npm install
npm run dev
```
